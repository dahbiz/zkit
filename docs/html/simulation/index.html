zkit.simulation

High-level simulation reader for TDSEZ.

class zkit.simulation.Run(run_dir, basename)

Bases: object

Read all outputs of a TDSEZ simulation run.

Parameters:

  • run_dir (Union[str, Path]) – Directory containing the td/ and static/ subdirectories.

  • basename (Union[str, Path]) – Input basename such as h2p.inp or full path to the input file.

Examples

>>> run = zkit.Run("build", "h2p.inp")
>>> run.dim
1
>>> run.dipoles.shape
(101, 4)
