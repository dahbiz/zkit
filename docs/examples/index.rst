Examples
========

This section contains reproducible workflows showing how to use zkit with
TDSEZ outputs.  The quick examples are designed as smoke tests: they run in
seconds, produce publication-style plots, and exercise static eigenvalue,
heterostructure, reconstruction, and time-dependent analysis paths.
